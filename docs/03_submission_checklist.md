# 提交前检查清单

## 论文内容

- [ ] 摘要不超过一页，包含方法、核心结果和结论。
- [ ] 正文不要目录，正文页数不超过官方要求。
- [ ] 每个问题都有对应模型、结果和解释。
- [ ] 图表有编号、标题、单位、数据来源和正文引用。
- [ ] 公式变量在首次出现处解释清楚。
- [ ] 模型假设具体、必要、可辩护。
- [ ] 优缺点分析和改进方向具体，不写空话。

## 复现材料

- [ ] 支撑材料包含所有可运行源程序。
- [ ] 数据契约与当前输入哈希一致，单位、时间顺序和连接键已人工核对。
- [ ] 至少一次最终实验有成功的 `experiments/*/manifest.json`，随机种子、参数和依赖版本齐全。
- [ ] 自主查阅的数据资料已放入支撑材料，赛题原始数据按要求处理。
- [ ] 中间结果、较大图表、参数表已放入 `outputs/` 或附录。
- [ ] 论文中的关键数值能由代码复现。
- [ ] `templates/claim_evidence_map.csv` 中的关键结论都有真实证据路径，且 `verified=yes`。
- [ ] 已运行 `python scripts/result_freeze.py check`，当前结果与冻结清单一致。
- [ ] 支撑材料文件列表已写入论文附录。

## 格式和匿名

- [ ] 电子论文首页是摘要专用页，不含承诺书和编号页。
- [ ] 论文、附录、代码、数据、图片中没有姓名、学校、赛区、学号、联系方式。
- [ ] 参考文献在正文中有引用标注。
- [ ] 电子论文与纸质论文内容和格式一致。
- [ ] 论文文件和支撑材料文件大小均不超过官方限制。

## AI 使用

- [ ] 论文参考文献前加入 AI 工具使用声明。
- [ ] 若使用 AI，支撑材料中包含详细使用说明 PDF。
- [ ] AI 输出已人工核验，核心建模和分析由队伍主导。
- [ ] 没有把 AI 生成内容直接作为核心建模结果提交。

## 最终动作

- [ ] 运行提交检查脚本：`powershell -ExecutionPolicy Bypass -File scripts/check_submission.ps1`。
- [ ] 由非主论文成员通读摘要、图表和结论。
- [ ] 由非主程序成员按说明运行代码。
- [ ] 运行 `python scripts/gatekeeper.py status`，确认 G1-G6 全部通过且 G4 不显示 `STALE`。
- [ ] 运行 `python scripts/audit_project.py --forbidden "学校全名" --forbidden "队员姓名"` 并得到 PASS。
- [ ] 队长最后确认选题、结论、风险和提交文件。
