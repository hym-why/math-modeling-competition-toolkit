# 支撑材料文件清单

将本清单复制到论文附录，并保证支撑材料压缩包中的文件与清单一致。

| 路径 | 内容 | 是否必要 | 复现说明 |
| --- | --- | --- | --- |
| code/main.py | 主程序入口 | 是 | 运行后生成主要图表和结果 |
| code/modeling_toolkit.py | 通用建模函数 | 是 | 被主程序调用 |
| data/ | 数据文件 | 是 | 包含赛题数据和公开数据 |
| outputs/ | 输出结果 | 是 | 包含论文引用的图表 |
| AI 工具使用详情.pdf | AI 使用记录 | 视情况 | 使用 AI 时必须提交 |
